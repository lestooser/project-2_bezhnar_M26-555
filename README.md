# Primitive Database

Консольная реляционная база данных на Python. Структура таблиц и записи хранятся в JSON-файлах. Проект создан в рамках учебного курса и демонстрирует процедурное программирование, декораторы, замыкания и организацию Python-проекта с помощью `uv` и `Ruff`.

## Возможности

- Создание, удаление и просмотр таблиц. При создании в таблицу автоматически добавляется первичный ключ `ID`.
- Типы столбцов: `int`, `str` и `bool`. Значения проверяются при добавлении записи.
- Операции с записями: добавление (`insert`), чтение (`select`), изменение (`update`) и удаление (`delete`).
- Условия для чтения, изменения и удаления записей.
- Сохранение метаданных и данных в отдельных JSON-файлах.
- Запрос подтверждения перед удалением таблиц и записей.
- Кэширование результатов `select`. Кэш сбрасывается при изменении данных.

## Технологии

- Python 3.12 или новее.
- [`uv`](https://docs.astral.sh/uv/) — управление зависимостями и виртуальным окружением.
- `prettytable` — вывод записей в виде таблицы.
- `prompt` — ввод команд в интерактивном режиме.
- `Ruff` — линтер и форматтер.
- `Make` — запуск часто используемых команд через `Makefile`.

## Установка и запуск

Установите Python 3.12+ и [`uv`](https://docs.astral.sh/uv/), затем клонируйте репозиторий:

```bash
git clone <URL-репозитория>
cd <каталог-репозитория>
```

Создайте виртуальное окружение и установите зависимости:

```bash
uv sync
```

То же действие можно выполнить командой `make install`.

Запустите приложение:

```bash
uv run database
```

Или используйте `make run`. После запуска введите команду в интерактивной оболочке. Для выхода используйте `exit`, для просмотра справки — `help`.

## Команды

### Управление таблицами

| Команда | Действие |
| --- | --- |
| `create_table <имя> <столбец:тип> ...` | Создать таблицу. Столбец `ID` добавляется автоматически. Типы: `int`, `str`, `bool`. |
| `list_tables` | Показать список таблиц. |
| `info <имя>` | Показать столбцы таблицы и количество записей. |
| `drop_table <имя>` | Удалить таблицу и её файл с данными. Требуется подтверждение. |

Например, команда `create_table users name:str age:int` создаёт таблицу `users` со столбцами `ID`, `name` и `age`.

### Операции с записями

Строковые значения можно указывать в кавычках. Числа и логические значения `true` и `false` указываются без кавычек.

| Команда | Действие |
| --- | --- |
| `insert into <имя> values (<значение1>, <значение2>)` | Добавить запись. Число значений должно совпадать с числом столбцов, кроме `ID`. |
| `select from <имя>` | Показать все записи. |
| `select from <имя> where <столбец> = <значение>` | Показать записи, удовлетворяющие условию. |
| `update <имя> set <столбец> = <значение> where <столбец> = <значение>` | Изменить записи, удовлетворяющие условию. |
| `delete from <имя> where <столбец> = <значение>` | Удалить записи, удовлетворяющие условию. Требуется подтверждение. |

Пример сеанса:

```text
Введите команду: create_table users name:str age:int
Таблица users создана

Введите команду: insert into users values ("Sergei", 28)
Запись с ID=1 успешно добавлена в таблицу "users".

Введите команду: select from users where age = 28
+----+--------+-----+
| ID |  name  | age |
+----+--------+-----+
| 1  | Sergei | 28  |
+----+--------+-----+

Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? (y/n): y
Таблица users удалена
```

## Хранение данных

Метаданные таблиц сохраняются в `db_meta.json`, записи — в отдельных файлах `data/<имя_таблицы>.json`. Каталог `data` и файл метаданных создаются или обновляются при выполнении соответствующих операций. При удалении таблицы удаляются её метаданные и файл с записями.

## Декораторы и кэширование

В `decorators.py` находятся декораторы и функция создания кэша:

- `handle_db_errors` обрабатывает `FileNotFoundError`, `KeyError`, `ValueError` и пользовательские ошибки базы данных, выводя сообщение вместо необработанного исключения.
- `confirm_action("...")` запрашивает подтверждение `y/n` перед выполнением действия. Используется для удаления таблиц и записей.
- `log_time` измеряет длительность выполнения функции с помощью `time.monotonic()`. Используется для `insert` и `select`.
- `create_cacher()` возвращает функцию с кэшем в замыкании. Она сохраняет результаты запросов `select`; кэш сбрасывается после `insert`, `update` и `delete`.

## Проверка кода

Проверить код линтером и применить форматирование можно командами:

```bash
make lint
make format
```

Или напрямую через `uv`:

```bash
uv run ruff check .
uv run ruff format .
```

Для сборки пакета используется `make build` или `uv build`.
