# Примитивная база данных (Primitive Database)

Простая консольная база данных, написанная на Python. Проект умеет создавать таблицы, хранить метаданные и данные в JSON-файлах, а также поддерживает полный набор CRUD-операций.

## Установка

Для работы с проектом используется пакетный менеджер `uv`.

1. Клонируйте репозиторий.
2. Установите зависимости и сам пакет:
```bash
uv sync
uv pip install .
Запуск
После установки база данных запускается одной командой в терминале:

bash
database
(Также можно запустить через python -m primitive_db.main)

Управление таблицами
В базе данных доступны следующие команды для работы со структурой таблиц:

create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ... — создать новую таблицу. Столбец ID создается автоматически.

list_tables — показать список всех существующих таблиц.

drop_table <имя_таблицы> — удалить таблицу (вместе со всеми её данными).

info <имя_таблицы> — вывести информацию о таблице (столбцы и количество записей).

Пример:

text
>>> Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана.
>>> Введите команду: list_tables
- users
CRUD-операции
База данных поддерживает полный набор операций с данными.
Обратите внимание: строковые значения (тип str) должны передаваться в кавычках, числа и true/false — без кавычек.

insert into <имя_таблицы> values (<значение1>, <значение2>, ...) — добавить новую запись.

select from <имя_таблицы> — вывести все записи таблицы.

select from <имя_таблицы> where <столбец> = <значение> — вывести записи по условию.

update <имя_таблицы> set <столбец1> = <новое_значение> where <столбец_условия> = <значение_условия> — обновить записи по условию.

delete from <имя_таблицы> where <столбец> = <значение> — удалить записи по условию.

Пример работы:

text
>>> Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".

>>> Введите команду: select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei | 28  |    True   |
+----+--------+-----+-----------+

>>> Введите команду: update users set age = 29 where name = "Sergei"
Запись в таблице "users" успешно обновлена.

>>> Введите команду: delete from users where ID = 1
Запись успешно удалена из таблицы "users".
